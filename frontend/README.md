# Frontend

These are the EstateOps web pages (plain HTML/CSS/JS):
- index.html  — landing page
- login.html  — sign in / create account
- app.html    — dashboard
- styles.css  — shared styles

The running application already serves these at http://localhost:8080 (the backend
bundles its own copy under backend/src/main/resources/static). This folder is a
standalone copy so you can preview the design by opening index.html in a browser.
Note: login and live data only work when the backend is running, because they call
its API.
