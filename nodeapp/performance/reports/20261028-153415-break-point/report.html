    Users grew 79% from "step 1" to "step 2" but throughput grew only 11% while p95 rose 86%. The system is close to its capacity around 43 users.
  • warning Throughput stopped scaling at "step 3"
    Users grew 47% from "step 2" to "step 3" but throughput grew only 3% while p95 rose 47%. The system is close to its capacity around 63 users.
  • warning Throughput stopped scaling at "step 5"
    Users grew 23% from "step 4" to "step 5" but throughput grew only -12% while p95 rose 88%. The system is close to its capacity around 101 users.
  • warning Server process CPU was saturated
    CPU of the server process was at or above 85% of one core for 43 of 118 seconds. Node.js handles requests on one thread, so this is a likely bottleneck.
  • warning Event-loop delay was high
    The event loop was delayed up to 2028.99 ms (p95 in a one-second window). Requests queue behind synchronous work such as password hashing, large JSON or database calls.
