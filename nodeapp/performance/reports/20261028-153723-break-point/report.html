    Users grew 23% from "step 4" to "step 5" but throughput grew only -8% while p95 rose 54%. The system is close to its capacity around 101 users.
  • warning Server process CPU was saturated
    CPU of the server process was at or above 85% of one core for 33 of 116 seconds. Node.js handles requests on one thread, so this is a likely bottleneck.

    The event loop was delayed up to 2146.44 ms (p95 in a one-second window). Requests queue behind synchronous work such as password hashing, large JSON or database calls.
