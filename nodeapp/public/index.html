AI that suggests. People decide.

When an administrator adds a Gemini API key, a manager can ask for a suggested category and priority for a request, then accept or ignore it.

  • Only the request title and description are sent to the AI service.
  • Suggestions are validated, stored for review, and never applied automatically.
  • If AI is not configured, EstateOps says so plainly and everything else works.
  • Insights for repeat issues and unusual costs use fixed rules over your own records, not AI.
